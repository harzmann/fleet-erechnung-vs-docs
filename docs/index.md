# FLEET E-Rechnung

Mit FLEET E-Rechnung prüfen, exportieren und versenden Sie Rechnungen aus dem FLEET-System. Dieses Portal begleitet die tägliche Arbeit und die Vorbereitung der benötigten Stammdaten.

## Ihr Einstieg

| Sie möchten … | Hier beginnen Sie |
| --- | --- |
| Eine Rechnung ansehen, exportieren oder versenden | [Endanwender-Handbuch](handbuch/index.md) |
| Die E-Rechnung erstmals einrichten | [Vorbereitung und Stammdaten](vorbereitung/index.md) |
| Einheiten oder Steuerkategorien zuordnen | [Mengeneinheiten](vorbereitung/mengeneinheiten.md) und [Steuersätze](vorbereitung/steuersaetze.md) |
| Eine Fehlermeldung verstehen | [Prüfen, Protokolle und Fehler](handbuch/pruefung.md) |
| Regelmäßige Verarbeitung einrichten | [Taskplaner](handbuch/taskplaner.md) |

## Empfohlener erster Ablauf

1. Lassen Sie die [Stammdaten und technischen Voraussetzungen](vorbereitung/index.md) vorbereiten.
2. Wählen Sie die Rechnungsart und eine einzelne Rechnung.
3. Prüfen Sie die [Vorschau](handbuch/berichte.md) und den [Validator-Bericht](handbuch/pruefung.md).
4. Exportieren Sie das vom Empfänger gewünschte Format.
5. Kontrollieren Sie das Ergebnisprotokoll vor einem Versand oder weiteren Verarbeitungslauf.

!!! info "Bezugsstand: 3. November 2026"
    Die Anleitungen beschreiben den geprüften lokalen Arbeitsstand des Produkts, einschließlich noch nicht eingecheckter Änderungen. Insbesondere bei manuellen Rechnungen bestehen [bekannte Grenzen](referenz/bezugsstand.md). Die Dokumentation enthält keine Softwaredownloads.

Die [offiziellen Quellen](referenz/quellen.md) erklären die verwendeten Codes und Rechnungsbegriffe. Die Produktbeschreibung folgt der vorhandenen Implementierung; ein erfolgreicher Dateiexport allein bedeutet noch keine erfolgreiche fachliche Validierung.
